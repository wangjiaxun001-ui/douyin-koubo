# 拾句 · 抖音口播提词器

在 Chrome 中打开一条能播放的抖音视频，点一下扩展，获得带时间的口播和按原话整理的脚本。不需要下载视频、录屏、打开麦克风、申请 API Key 或安装后台服务。

## 安装（一次）

先[下载完整插件 ZIP](https://github.com/wangjiaxun001-ui/douyin-koubo/archive/refs/heads/main.zip) 并解压，压缩包已包含离线识别模型。

1. 在 Chrome 地址栏输入 chrome://extensions 并回车，打开右上角「开发者模式」。
2. 点「加载未打包的扩展程序」，选择本项目里的 **extension** 文件夹（里面有 manifest.json）。Mac 的文件选择框中可以按 ⌘⇧G 粘贴目录路径。
3. 在 Chrome 工具栏的拼图菜单中找到「拾句 · 抖音口播提词器」，点图钉。

## 提取与复制

1. 用桌面 Chrome（116 或更高）打开抖音分享链接。短链接需要先跳转到可以播放的网页版作品。如果是登录、验证或 App 引导页，请先在网页里打开实际作品。
2. 点击工具栏「拾句」→「提取当前视频」。优先读当前作品公开的字幕轨或页面明确提供的带时间字幕。字幕范围不足时会改听原声；画面上烧录的字幕同样走原声。网页字幕可能是编辑过的；要按原声核对，可在「提取选项」选择「忽略网页字幕」。
3. 无字幕时插件会将视频退回开头、以正常速度播放一次。保持标签页打开、不要拖进度或翻到下一条。可以收起插件，稍后在同一浏览器中重新打开看进度。去掉网页播放器的静音是为了取得声音，结束后恢复原来的音量、静音、循环和倍速设置。
4. 点「复制逐字稿」或「复制脚本拆解」，粘贴到飞书或聊天框。拆解按措辞和顺序标注开场、步骤、举例、收尾等，保留原话；同一音频段拆出的句子共用时间范围。自动识别可能漏掉语气词、听错专名、方言或数字，不能保证逐字无误。
5. 点「停止并保留已有文字」可提前结束。进度被拖动、中途跳转等情况会标为未完成，复制时也带上标记。

## 数据和空间

只在你点提取后读取当前作品。标签页声音在本机内存中短暂分段处理；不请求视频流，不写音视频文件，不调用云端识别。播放器本身仍会正常使用 Chrome 的网络和缓存。模型随插件附带（安装目录约 90 MiB），不用每条视频重复下载。只在浏览器会话中保留最近一次任务的文字；开始下一个任务会覆盖它，重启浏览器会清空。如果要长久保留请及时复制。一次处理一条视频，直播不支持。

## 测试

tests/browser.cjs 使用 Chrome for Testing 的真实工具栏弹窗、标签页音频和系统剪贴板接口。设置 CHROME 为测试版浏览器可执行文件路径、NODE_PATH 为含 playwright 的模块目录、TEST_VOICE 为中文语音 WAV，然后运行 node tests/browser.cjs。测试语音：「今天我们来做一个测试。打开手机，把视频链接复制下来。最后记得检查文字。」可用 Mac 的 say -v Tingting -r 165 生成，再用 afconvert 转 16 kHz 单声道 WAV。LIVE=1 可单独运行公开作品测试，结果取决于页面当时是否可播放。

引擎、来源、版本见 extension/engine/NOTICE.txt。

2026-11-11 本机实测（Chrome for Testing 157，macOS）：
- 在扩展工具栏弹窗读取双句 VTT，保留「嗯，嗯」，并从剪贴板读回核对逐字稿和脚本拆解。
- 无字幕中文样本预先停在第 2 秒，提取后听写覆盖开头「今天我们来做一个测试」到结尾「最后记得检查文字」。
- 实际公开作品 https://www.douyin.com/video/7686819974069128483 在此次测试可正常播放。本地识别从头处理到 60.001 秒，输出 3 段文字。此项验证实际页面和完整播放流程，没有人工逐字校对该作品。

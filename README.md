# 拾句 · 抖音口播提词器

在 Chrome 中打开一条能播放的抖音视频，点一下扩展，获得纯文字逐字稿和带时间的脚本拆解。不需要下载视频、录屏、打开麦克风、申请 API Key 或安装后台服务。

## 安装（一次）

先[下载完整插件 ZIP](https://github.com/wangjiaxun001-ui/douyin-koubo/archive/refs/heads/main.zip) 并解压，压缩包已包含离线识别模型。

1. 在 Chrome 地址栏输入 chrome://extensions 并回车，打开右上角「开发者模式」。
2. 点「加载未打包的扩展程序」，选择本项目里的 **extension** 文件夹（里面有 manifest.json）。Mac 的文件选择框中可以按 ⌘⇧G 粘贴目录路径。
3. 在 Chrome 工具栏的拼图菜单中找到「拾句 · 抖音口播提词器」，点图钉。

## 提取与复制

1. 用桌面 Chrome（116 或更高）打开抖音分享链接。短链接需要先跳转到可以播放的网页版作品。如果是登录、验证或 App 引导页，请先在网页里打开实际作品。
如果已经打开拾句的独立提取页，可以点「连接视频并提取」，允许访问抖音后选择本窗口中的作品。

2. 点「拾句」→「快速提取当前视频」。插件优先读取当前作品的完整网页字幕。勾选「忽略网页字幕」可以直接按原声转写。
3. 没有完整字幕时，插件会尝试读取当前作品的独立音轨，或读取播放器直接提供的媒体并解码声音。视频可以保持暂停。转写在本机完成，处理中只显示进度，完成后一次显示全文。
4. 从搜索弹窗、观看历史或推荐页提取时，拾句按当前作品编号匹配播放器提供的音轨。若弹窗没有完整媒体地址，会自动将当前标签页切到同一作品的独立页面，核对编号和时长后继续提取；只自动重试一次。视频无需从头播放。快速识别和原声精校支持 45 分钟以内的视频，读取音轨时单个媒体响应上限为 512 MiB，下载时显示已读取大小。
5. 点「复制逐字稿」或「复制脚本拆解」，粘贴到飞书或聊天框。自动识别可能听错同音字、人名或品牌名，发布前请对照原声。
6. 点「停止并保留已有文字」可提前结束。复制未完成的稿件时会带上标记。

## 数据和空间

只在你点提取后读取当前作品。音频在内存中处理，不写音视频文件，也不调用云端识别。浏览器可能正常使用网络和缓存。插件自带离线模型，安装目录约 90 MiB。只在浏览器会话中保留最近一次任务的文字，重启浏览器会清空。

## 测试

`node --test tests/audio-read.cjs tests/search-recovery.cjs` 检查音轨读取、错误提示及搜索弹窗自动恢复，覆盖作品编号冲突、用户切换视频、停止、加载超时和防止重复跳转。这些是本地模拟回归测试，不代表真实抖音作品已完成转写。

tests/browser.cjs 使用 Chrome for Testing 的真实工具栏弹窗、暂停的播放器、作品音轨和系统剪贴板接口。设置 CHROME 为测试版浏览器可执行文件路径、NODE_PATH 为含 playwright 的模块目录、TEST_VOICE 为中文语音 WAV，然后运行 node tests/browser.cjs。测试语音：「今天我们来做一个测试。打开手机，把视频链接复制下来。最后记得检查文字。」可用 Mac 的 say -v Tingting -r 165 生成，再用 afconvert 转 16 kHz 单声道 WAV。LIVE=1 可单独运行公开作品测试，结果取决于页面当时是否可播放。

引擎、来源、版本见 extension/engine/NOTICE.txt。

## 把一段原话加入选题卡（1.2.0）

在同一个 Chrome 配置里启用「拾句」和「半吊牌 · 评论区选题夹」0.4.0。打开单条作品，提取后在「选一段口播」中选中一句，点「加入已有选题卡」。在打开的选题夹里选择目标卡，点「加入这张卡」。选题卡上的 ▶ 时间可重新打开原作品并跳到这句话；旧任务没有可靠作品编号时，需要在原作品页重新提取。

第一版配对的是本机从原文件夹加载的两个扩展。移动文件夹或换电脑可能改变解压扩展的 ID，需要重新配对。所选片段保存在选题夹的扩展页面；双击打开的 HTML 预览有独立的卡库。

### 文案对比与作品数据（1.3.1）

在抖音作品页打开拾句，提取后点「把整篇加入文案对比」。每一列对应一篇文案，列头展示作者粉丝数、该作品点赞数和评论数。拾句只带入能匹配到当前作品的数据；横线代表未获取，0 表示读到的值确实是 0，网页版显示的「万」保留原精度。

编辑页按「录入文案 → 对比挑段 → 排列段落 → 最终成稿」排列。旧选题和手改的最终稿会保留。已有来源链接的文案，点「原视频」后在拾句点「只更新作品数据」，无需重新听写；也可以点列头的「编辑数据」手填。手填数据单独标记，核实到新的抖音原页数字后会更新。对比页左上角的「← 提取口播」可回到原来的提取页；打开旧选题只读本地记录，不逐条访问抖音。复制和导出的 TXT 仅包含最终文案。

### 可选 AI 改稿与博主参考稿（1.4.0）

在「录入文案与作品数据」粘贴自己的原稿。打开「启用 AI 改稿」，选择原稿栏和 DeepSeek、Gemini 或豆包，填写修改要求和该服务的 API Key，点击「根据原稿生成改稿」。如有需要可更换模型 ID。每次生成一版，保留原稿及已有改稿，结果可继续编辑、分段和挑选。API Key 只用于当前页面，不写入选题库。请求直接发往所选服务，额度和计费以该账户为准。

没有 API Key 时，可点「复制改稿提示词」，粘到常用 AI 对话中，再将回复贴回文案栏。关闭 AI 后可继续点「＋ 添加博主文稿」、粘贴参考稿，再点「分段并对比」。旧选题保留原有栏目。

## 安装卡卡字幕（macOS Chrome）

在拾句项目根目录运行以下命令，需要 Python 3.10 至 3.12。用 Chrome 加载本项目的 `extension` 目录；若更换目录，重新运行注册脚本。

```sh
KAKA_DIR="$HOME/Library/Application Support/Shiju/VideoCaptioner"
python3.12 -m venv "$KAKA_DIR/runtime"
"$KAKA_DIR/runtime/bin/python" -m pip install videocaptioner==1.4.2 httpx==0.28.1
"$KAKA_DIR/runtime/bin/python" native/register_kaka.py
```

重新加载拾句，提取一篇逐字稿，点「卡卡字幕 · 断句校对」，首次使用按 Chrome 提示允许连接本机应用。卡卡校对页保留网页字幕或识别引擎提供的每行文字及起止时间，可逐句编辑、复制纯文字或导出 SRT。校对稿单独暂存在当前浏览器会话中。

可选的「AI 校正错字」使用卡卡自带的校正提示词。填入自己的 DeepSeek 密钥和模型 ID，点发送按钮后才会提交字幕文字。密钥只用于本次页面，不写入存储。


原声精校需要安装 faster-whisper、简繁转换和本机模型。安装一次后即可离线运行。在上述环境执行：

```sh
"$KAKA_DIR/runtime/bin/python" -m pip install faster-whisper==1.2.1 opencc-python-reimplemented==0.1.7 pyobjc-framework-Vision Pillow
"$KAKA_DIR/runtime/bin/python" -c 'from faster_whisper.utils import download_model; import sys; download_model("Systran/faster-whisper-small", output_dir=sys.argv[1])' "$KAKA_DIR/models/whisper-small"
```

「快速提取当前视频」优先使用完整网页字幕。没有字幕时，本机精校用原声中的词时间、停顿和标点分行，保留说话之间的空白。精校用时较长，可在「提取选项」切换快速识别，也可填写本条视频的人名、品牌名提示精校。对只有画面字幕的作品，精校模式会在本机用 macOS Vision 寻找与原声相符的字幕位置，按换行采样（约 0.3 秒）。字幕读取不完整时使用原声结果；勾选「忽略网页字幕，按原声重新听写」也会跳过画面识别。
